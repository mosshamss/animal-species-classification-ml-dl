# Dataset setup

The image dataset is not included because the source archive is large and is distributed by its original publisher.

1. Download **Animals-10** from Kaggle: https://www.kaggle.com/datasets/alessiocorrado99/animals10
2. In Google Drive, create the folder `MyDrive/animal_class`.
3. Upload the downloaded ZIP archive to that folder with the exact name `archive.zip`.
4. Run the notebook in Google Colab and grant Google Drive access when asked.
5. The notebook extracts the archive to `/content/animals10` and expects an `raw-img` subfolder. If the archive contains another directory structure, adjust its extraction path.

No dataset images or model weights are included in this repository. The repository's charts are original outputs from the supplied analysis notebook.
